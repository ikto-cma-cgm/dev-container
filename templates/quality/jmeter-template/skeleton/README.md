## Quick Start

### Prerequisites

- Docker Desktop (Mac/Windows) or Docker Engine (Linux)
- Docker Compose v2.x

### Run Your First Test

```bash
# 1. Navigate to the jmeter directory
cd jmeter

# 2. Copy the environment template
cp .env.example .env

# 3. Run the tests
docker-compose up
```

The first run builds the Docker image (takes 2-3 min), then subsequent runs are instant.

### View Results

After the test completes:

```bash
# Open the HTML report
open reports/index.html
```

## Configuration

### Environment Variables

Edit `.env` or set environment variables:

```bash
# Target
TARGET_HOST=your-api.com
TARGET_PORT=443
TARGET_PROTOCOL=https

# Load
THREADS=${{ values.defaultThreads }}
DURATION=${{ values.defaultDuration }}

# Test plan
TEST_PLAN=api/load-test.jmx
```

### Run with Custom Settings

```bash
# Test with more threads
THREADS=50 docker-compose up

# Longer duration test
DURATION=300 docker-compose up

# Different environment
TARGET_HOST=staging.example.com TARGET_PORT=443 TARGET_PROTOCOL=https docker-compose up
```

## Troubleshooting

### Tests won't start

```bash
# Check Docker is running
docker ps

# Check test plans exist
ls -la test-plans/api/

# Check environment variables
docker-compose config
```

### Memory issues

```bash
# Increase heap in .env
HEAP=-Xms2g -Xmx4g -XX:MaxMetaspaceSize=512m
docker-compose up
```

### Permission errors

```bash
# Fix directory permissions
chmod -R 755 results/ reports/
```

## Reports

The HTML Dashboard includes:

- **Overview** - APDEX score, summary statistics
- **Over Time** - Response times, active threads, throughput
- **Throughput** - Transactions per second
- **Response Times** - Distribution, percentiles
- **Errors** - Top errors by request

## Best Practices

1. **Start small** - Begin with few threads, increase gradually
2. **Monitor** - Watch your application's resource usage during tests
3. **Realistic data** - Use production-like test data
4. **Assertions** - Add response code and content assertions
5. **Think time** - Add realistic delays between requests
